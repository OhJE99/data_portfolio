# 오정은 데이터 프로젝트 포트폴리오

HTML/CSS를 원본으로 관리하고 Chrome에서 16:9 PDF로 출력하도록 구성한 14페이지 포트폴리오입니다.

## 실행 방법

별도 빌드나 패키지 설치가 필요 없습니다. `index.html`을 Chrome으로 열면 됩니다.

로컬 서버로 확인하려면 이 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`에 접속합니다.

```bash
python3 -m http.server 8000
```

화면 우측 하단 버튼 또는 키보드 방향키와 Page Up/Down으로 슬라이드를 이동할 수 있습니다. 이 내비게이션은 인쇄물에는 표시되지 않습니다.

## PDF 출력 방법

1. Chrome에서 `index.html`을 엽니다.
2. 웹폰트가 로드될 때까지 잠시 기다립니다. 네트워크가 없다면 Apple SD Gothic Neo 등 시스템 한글 폰트로 대체됩니다.
3. `Cmd + P`(macOS) 또는 `Ctrl + P`(Windows)를 누릅니다.
4. 대상을 **PDF로 저장**으로 선택합니다.
5. 아래 권장 설정을 적용하고 저장합니다.

## Chrome Print 권장 설정

- 레이아웃: 가로
- 용지 크기: CSS에서 지정한 사용자 크기(13.333 × 7.5 inch)
- 페이지: 전체
- 페이지당 시트 수: 1
- 배율: 기본값 또는 100%
- 여백: 없음
- 옵션 → 배경 그래픽: 켬
- 옵션 → 머리글과 바닥글: 끔

`print.css`의 `@page`가 13.333 × 7.5 inch를 지정하며, 각 `.slide`는 강제 페이지 분리되어 PDF 한 페이지가 됩니다. Chrome 미리보기에서 총 14페이지인지 확인하세요.

## 수정 안내

- 콘텐츠와 마크업: `index.html`
- 화면 디자인: `styles.css`
- PDF 출력 전용 규칙: `print.css`
- 브라우저 탐색 기능: `script.js`

인쇄 전에 Chrome의 **배경 그래픽** 설정이 활성화되어 있는지 반드시 확인하세요. 기본 header/footer를 켜면 페이지 가장자리에 URL과 날짜가 추가되므로 반드시 비활성화합니다.
